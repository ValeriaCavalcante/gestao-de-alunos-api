# API

Projeto desenvolvido para a pós-graduação em Automação de Testes - API.
API pra mim, é uma forma muito complicada de atuar, portanto usei ajuda de IA. 

A API simula um sistema simples de uma escola, onde é possível:

- Cadastrar alunos;
- Fazer login;
- Matricular alunos em disciplinas;
- Registrar trabalhos.

## Tecnologias utilizadas

- Node.js
- Express
- Mocha
- Chai
- Supertest
- GitHub Actions

## Testes automatizados

Foram criados testes para verificar algumas funcionalidades da API:

- Login;
- Cadastro de aluno;
- Matrícula do aluno;
- Entrega de trabalho.
